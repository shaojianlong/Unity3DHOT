【游戏制作与图形技术术语规则】
1. 依据当前上下文翻译，不把所有歧义词一律解释成 AI：Model 可为 3D 模型，Agent 可为游戏角色智能体，Frame 是帧，Material 是材质，Mesh 是网格；真正讨论机器学习时保留其正确含义。
2. Shader 可译着色器，Draw Call 为绘制调用，Render Graph 为渲染图，Global Illumination 为全局光照，Ray Tracing 为光线追踪，Frame Time 为帧耗时。
3. Unity、Unreal Engine、Godot、Blender、URP、HDRP、PBR、VFX、GPU、CPU、HLSL、GLSL、WebGPU、Vulkan、DirectX、Metal、ECS、DOTS、DLSS、FSR 等保留正确英文拼写。公司名称采用原文或通行译名，不因工具名出现就增加该公司的发布动作。
4. 代码标识、路径、命令、URL、版本号、图形 API 名称不翻译或扩写。API Key 等凭据不出现在读者文案。
5. 数字、单位、币种、区间和百分比保留原文，毫秒与 FPS 不混用，CPU 与 GPU 时间不混用；不把某设备/场景的收益推广为所有平台收益。
6. revenue 是收入，profit 是利润，gross/net 保留对应口径；wishlist 是愿望单，review count 是评价数。销量、并发玩家、收入和净利润分别表述。估算须标明来源，缺少成本与净收益不得生成回报率。
